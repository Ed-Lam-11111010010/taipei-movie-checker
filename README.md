# Taipei Movie Checker

Static preview of publicly available Taipei cinema showtimes. Movie posters and film links point to official sources. Sessions are sorted by start time; started sessions are hidden using Taipei time.

This repository contains website output only. No local settings, credentials, project notes, or backend source are included.

The refresh button loads the latest published snapshot. Cinema-source synchronization is not scheduled on this website. Always check the displayed source timestamp and the official cinema pages for changes.
