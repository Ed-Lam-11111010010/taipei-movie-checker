# Taipei Movie Checker — 真實場次入口 + 測試介面

## 真實電影場次（由來源網頁提供）

本網站新增 12 間台北／新北影城的「查看最新場次」入口，點選後會直接前往威秀官方戲院頁、國賓官方場次頁或開眼電影網的欣欣秀泰場次頁。**最新場次請以外部來源當下顯示為準。**

目前這個 GitHub Pages 版本**沒有自動擷取或顯示真實即時場次**，並未啟用台北時間每日 08:00 的同步排程。請勿將前往外部場次頁的連結視為站內即時同步。

## 網站功能測試（虛構場次）

頁面下方仍保留 672 筆虛構場次，用來測試電影搜尋、多選、時間排序、日期切換、影城與地圖。**所有測試電影與放映時間都是虛構的，不能用於訂票。** 點選「更新場次」只會重新載入同一份靜態測試快照。

專案仍依既有的來源權限、快取、同步收據、時間新鮮度、發布驗證及 GitHub Pages 四檔白名單，另行進行真正的自動更新部署。這次更新不觸發戲院網站請求、不修改本機 private configuration、不註冊 Windows 工作排程。
