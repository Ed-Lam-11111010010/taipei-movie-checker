# Movie Checker — 個人非商業 POC｜台北電影場次查詢

Movie Checker 是我用來探索電影場次查詢介面的**個人、非商業概念驗證（Proof of Concept, POC）**網站。這是一個小型實驗專案，不是影城官方服務、商業資料平台或售票網站。

## 查看最新電影場次

網站提供 **12 間台北／新北影城**的場次來源入口，可前往威秀、國賓的官方相關頁面，以及欣欣秀泰的開眼電影網場次頁。**最新片名、日期、時刻與訂票資訊，請以來源網站當下顯示為準。**

目前 GitHub Pages **尚未啟用真實電影場次同步**；不會在背景擷取影城資訊，也未啟用台北時間每日 08:00 的自動更新。外部場次連結不等於本站已完成即時同步。

## 網站操作測試

頁面另外保留 **672 筆虛構測試場次**，只用於搜尋、電影多選、日期切換、時間排序、影城篩選與地圖功能驗證。這些片名或放映時間**並非真實場次，不能用來訂票或規劃觀影**。

「重新載入測試場次」只會重新讀取目前的靜態測試資料，不會向影城發出即時場次查詢。

## 資料與發布原則

個人非商業 POC 不代表取得了第三方網站的自動擷取、快取或公開再展示許可。若未來開啟真正的同步功能，仍須核實各來源條件、完成新鮮度與同步收據驗證，並在確認公開網站已成功更新後，才考慮清理舊資料。

此 GitHub Pages repository 只保留網站核准的四個公開檔案：`index.html`、`catalog.json`、`README.md` 與 `.nojekyll`。此版本不包含私人同步設定或排程。
