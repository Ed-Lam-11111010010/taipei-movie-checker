# Movie Checker — 個人非商業 POC｜台北電影場次查詢

Movie Checker 是我用來探索電影場次查詢介面的**個人、非商業概念驗證（Proof of Concept, POC）**網站。這是一個小型實驗專案，不是影城官方服務、商業資料平台或售票網站。

## 查看最新電影場次

網站提供 **12 間台北／新北影城**的場次來源入口，可前往威秀、國賓的官方相關頁面，以及欣欣秀泰的開眼電影網場次頁。**最新片名、日期、時刻與訂票資訊，請以來源網站當下顯示為準。**

目前 GitHub Pages **尚未啟用真實電影場次同步**；不會在背景擷取影城資訊，也未啟用台北時間每日 08:00 的自動更新。外部場次連結不等於本站已完成即時同步。

## 網站操作測試

頁面另外保留 **672 筆虛構測試場次**，只用於搜尋、電影多選、日期切換、時間排序、影城篩選與地圖功能驗證。這些片名或放映時間**並非真實場次，不能用來訂票或規劃觀影**。

「重新載入測試場次」只會重新讀取目前的靜態測試資料，不會向影城發出即時場次查詢。網站會依台北當天日期，在瀏覽器將固定的 14 天**虛構**場次範例平移至未來 14 天，以免過期後失去介面測試用途；這**不是**即時同步或真實場次更新。

## 在瀏覽器匯入個人場次（POC）

GitHub Pages 現在支援 **本機 CSV 匯入**，讓使用者在自己的瀏覽器測試電影、影城及時間排序，而不需要把未經授權的第三方資料推到公開網站。

1. 打開網站，在「個人場次 CSV 匯入」區塊點選「下載 CSV 範本」。
2. 按照範本填入已確認可自行使用的場次，欄位為 `cinemaId,title,date,time,format`。例如影城代碼 `vieshow-xinyi`（信義威秀）；日期格式 `YYYY-MM-DD`、時間 `HH:mm`，一律使用台北時間。
3. 以「選擇檔案」匯入 CSV，即可使用原有的搜尋、日期、版本篩選及地圖功能。一次最多 2,000 筆、檔案 256 KB 以下；只能使用網站追蹤的 12 間影城，且日期須在今天起 180 天內。
4. 也可展開「直接貼上 CSV 文字」，貼入同一格式後按「預覽貼上的場次」，無需建立檔案。貼上內容同樣受 256 KB、2,000 筆限制。
5. 匯入資料僅保存在目前頁面的記憶體中，**不會上傳 GitHub、呼叫影城網站、更新伺服器快照或自動儲存**。按「恢復測試場次」或重新整理頁面即可返回原本的 672 筆虛構範例。

**注意：** 手動匯入場次會清楚標示為「個人匯入 · 未經驗證」，並不是由本站抓取的即時官方場次；點選影城來源頁可自行核對。CSV 範本內的資料只是示例，不是實際放映安排。

GitHub Pages 上的「重新載入測試場次」會重新讀取同目錄的 `catalog.json`，但不會向任何影城同步場次。

## 資料與發布原則

個人非商業 POC 不代表取得了第三方網站的自動擷取、快取或公開再展示許可。若未來開啟真正的同步功能，仍須核實各來源條件、完成新鮮度與同步收據驗證，並在確認公開網站已成功更新後，才考慮清理舊資料。

此 GitHub Pages repository 只保留網站核准的四個公開檔案：`index.html`、`catalog.json`、`README.md` 與 `.nojekyll`。此版本不包含私人同步設定或排程。
