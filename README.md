# Movie Checker — 個人非商業 POC｜台北電影場次查詢

Movie Checker 是個人非商業概念驗證網站，不是影城官方服務，也不處理售票交易。

## 查看已發布的來源場次快照

GitHub Pages 會在進入網站時讀取同目錄的 `catalog.json`，**預設展示目前已成功取得的真實來源場次快照**，而不是虛構展示場次。頁面會顯示來源狀態、快照時間和各來源的成功／失敗資訊，並可透過「查看場次」開啟原始來源網站。

資料來源涵蓋 12 間台北與新北影城：

- 威秀影城：9 間影城會先嘗試各自的官方場次頁；若官方站拒絕 GitHub Actions 的自動存取，改用已核對影城身分的開眼電影網影城專頁，並在來源狀態明確標示備援，不會偽稱官網同步成功
- 國賓影城：國賓大戲院、台北長春國賓影城的官方場次頁
- 欣欣秀泰影城：開眼電影網的欣欣秀泰場次頁

**這不是即時訂票服務。** 已取得資料只代表取得當下來源頁的場次；最新放映時間、取消或售完狀態必須以原始網站為準。某來源未成功取得資料，不代表當日無電影放映。來源檢查超過 12 小時，網站會顯示可能過期提示。

最初發布的人工核對快照包含 2026-11-03 至 2026-11-04、3 間影城的 85 個場次。**2026-11-03 的後續排程已成功提交 1,626 筆可解析場次，涵蓋 12 間影城**：兩間國賓直接由官方頁取得，其餘十間採開眼電影網場次頁；威秀官方網頁對 GitHub Actions 回傳 HTTP 403，故採明確標記的備援來源。這次開眼資料主要涵蓋 11/04 與 11/05，11/03 部分日期頁沒有提供可解析場次；這不等於影城沒有營業。以最新 `catalog.json` 及各來源狀態為準，往後每次執行的數量可能不同。來源擷取失敗時不會以虛構資料補齊。

## 電影海報

場次卡片會使用**與該電影來源連結直接配對**的海報：國賓採其官方電影場次頁的圖片，其他來源採開眼電影網影城場次頁對應電影的圖片。同步程式只接受相符的電影 ID 或來源電影頁及限定的 HTTPS 圖片路徑，不會根據相似片名猜測圖片。

海報會隨來源快照更新，點擊海報可查看來源電影介紹頁。若來源未提供圖片、外站拒絕載入或配對驗證失敗，卡片會保留「暫無海報」替代顯示。圖片本身仍由原始來源主機提供，本儲存庫不存放電影海報檔案。

## GitHub Actions 更新流程

工作流程：`.github/workflows/sync-showtimes.yml`，解析器：`scripts/sync-showtimes.cjs`。

- 每天台北時間約 02:00、08:00、14:00、20:00 排程檢查，也可從 GitHub Actions 手動執行。實際執行時間受 GitHub 排程延遲影響。
- 以唯讀 HTTP 請求讀取來源頁，解析中文片名、日期、版本、時刻及來源網址，依影城和日期產生場次。
- 驗證日期範圍、時間格式、來源主機、唯一鍵及場次數後，才提交 `catalog.json`，由 GitHub Pages 發布。
- 若來源無法讀取或解析，會記錄錯誤狀態；若所有來源都無法產生足夠資料，工作流程會失敗並保留已發布的快照。這時網站會根據快照年齡提示資料可能過期。
- 解析依賴來源網頁結構及 GitHub Actions 的網路連線；網站改版或站方存取限制可能導致來源暫時不可用。請查看 Actions 記錄確認實際成功的影城與場次數，不要僅以 workflow 存在推定同步成功。

## 虛構資料測試模式

點選「查看虛構測試資料」，可切換到 **672 筆虛構測試場次**，測試電影多選、日期、時間排序、影城篩選及地圖。虛構資料在瀏覽器會平移成以台北今天起算的 14 天，**絕非真實電影場次**。點「返回來源場次」可回到目前已發布的快照。

## 在瀏覽器匯入個人 CSV（POC）

可在「個人場次 CSV 匯入」區塊選擇 CSV 檔案，或展開「直接貼上 CSV 文字」貼入資料。欄位為 `cinemaId,title,date,time,format`；日期 `YYYY-MM-DD`、時間 `HH:mm`，採台北時間。影城代碼須為本站追蹤的 12 間之一，單次最多 2,000 筆、256 KB、日期須在未來 180 天內。

**個人匯入的資料只保存在當下瀏覽器記憶體，不會上傳 GitHub、更新公開快照或向影城發送請求。** 重新整理或「恢復已發布場次」即可回到公開快照。匯入內容一律標示「未經驗證」。

## 公開檔案與來源

GitHub Pages 網頁資產為 `index.html`、`catalog.json`、`README.md` 和 `.nojekyll`。為實作自動更新，repo 額外包含 `.github/workflows/sync-showtimes.yml` 與 `scripts/sync-showtimes.cjs`，不包含 API 密鑰或私人同步設定。

來源網站內容可能受到各網站的使用條款與更新政策規範。這個小型個人 POC 只顯示必要的事實性場次欄位及來源連結，不代理售票、不保證資料完整性或使用權；如來源條款不允許持續自動存取，應停用相關解析來源。
